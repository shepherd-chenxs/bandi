# 班底

把活派给 AI 数字员工，看它干，随时接管。

- **数字员工**：创建不同岗位的成员，绑定你的 agent CLI，让它读代码、写代码、修 Bug、做测试。
- **实时过程**：每条消息都是一次真实执行，能看到思考、工具调用和回复，也能随时停止。
- **项目群聊**：按项目拉群派活，成员之间可以互相接力，群里 @ 谁就由谁接。
- **任务看板**：项目卡片、聊天派活、手工建卡统一管理，能看状态、评论和交付记录。
- **流程自动化**：把多步工作编排成流程，指定谁办哪一步，部署类动作仍由人确认。
- **本地优先**：自托管运行，数据和工作目录都留在你自己的机器上。

## 快速开始

1. 下载 Windows 桌面版：<https://github.com/shepherd-chenxs/bandi/releases/latest>
2. 安装后打开「班底」，用身份中枢账号登录。
3. 创建第一个数字员工，填姓名、岗位、职责和运行环境。
4. 在「消息」里发一句活，实时看它执行。

想改代码或使用 Linux / macOS，看 [docs/快速开始.md](docs/快速开始.md)。
