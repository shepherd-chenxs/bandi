# PR 审阅判据台账

正文在 [references/审阅经验.md](references/审阅经验.md)：十条判据、红线与黄线、三类回复模板。

它为什么是技能而不是 docs/ 里的文档（2026-11-24 定）：运行时要**照着做**的材料必须走技能库 ——
技能有登记表兜底，文件没了自动从清单消失；写死在提示词里的 docs/ 路径没人管，改名就静默 404。

维护规矩：每次判断出**新的**判据，往那份台账**追加一条**（现象 → 判据 → 处置 → 来源）；
只写已经能落到具体动作上的。出处（pr-watch / repo-scan 的提示词）只指路到这里，不复制内容。
