# 快速开始

## 安装桌面版（Windows）

1. 打开 [Releases](https://github.com/shepherd-chenxs/bandi/releases/latest)，下载 `bandi_<版本>_x64-setup.exe`。
2. 双击安装。安装包自带 Node 运行时，无需另装环境。
3. 打开「班底」，用身份中枢账号登录；桌面壳会保持本机会话，后续不用反复登录。

安装包没有代码签名，Windows 可能提示「未知发布者」；确认来源后可选「仍要运行」。校验和见 Release 页的 `SHA256SUMS-v<版本>.txt`。

卸载时可选「完全卸载」连数据一起删除；默认卸载和静默卸载都不删数据。

## 从源码运行

适用于改代码、Linux 和 macOS。

```sh
node --version
node start.mjs
```

- 需要 Node 22 或更高版本。
- 默认地址是 <http://127.0.0.1:18787/>。
- 仓库零依赖，不需要 `npm install`。
- Windows 也可以直接双击 `start.cmd`。
- 数据默认落在用户目录；Windows 是 `%APPDATA%\bandi`，可用 `BANDI_DATA` 改位置。

控制面默认监听 `0.0.0.0` 并强制鉴权。只想本机调试时，用 `BANDI_HOST=127.0.0.1 node start.mjs`。

## 命令行

安装桌面版后可用 `bandi`；源码检出可直接用仓库里的 `bandi.cmd`。

```sh
bandi                     # 状态一屏；交互终端还会给编号菜单
bandi status --json       # 给脚本读；退出码 3 表示没在跑
bandi start|stop|restart  # 起停；restart 会打断正在跑的活
bandi url --open          # 显示访问地址并打开浏览器
bandi logs -n 50 -f       # 查看日志
bandi mode                # 本机形态
bandi install-cli         # 重新注册全局命令
```

## 前置条件

- agent CLI 自己安装、凭据自备；班底只负责调用，不分发它们。
- 单机是唯一形态（多机节点子系统已于 2026-11-09 删除）；需要远程访问走 SSH 隧道或 TLS，需要跨机器协作时项目走 git 仓库和 PR，见 [../deploy/README.md](../deploy/README.md)。

## 安全

班底会在你的机器上执行命令。默认监听地址和鉴权规则见 [../SECURITY.md](../SECURITY.md)。不要把控制面直接暴露到公网；需要远程访问时走 SSH 隧道或 TLS。
