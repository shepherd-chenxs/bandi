# 本机壳子自动进门（/shell/enter）

> 2026-11-10。起因：用户在桌面壳里发消息，弹 `E4010 需要登录或访问令牌（这个请求不是从本机直接发起的）`。

## 现场

- 壳窗口里的页面在同一台机器上（`127.0.0.1:18787`），但控制面**默认对外监听 0.0.0.0**
  → `classifySource()` 第 ③ 条：监听非回环时，**回环 peer 也判 network**，所有请求都要鉴权
  （2026-11-03 起的有意设计，不是 bug）。
- 桌面壳的窗口本来靠 `?token=` 自动进门；但 2026-11-01「令牌不是人」之后，面板 HTML 只认
  登录会话，带令牌 Cookie 抓首页会**被清 Cookie 并画登录页** —— 壳每次打开都落在登录页。
- 本机会话只有「空闲 30 分钟 / 绝对 12 小时」。用户离开一晚（本次 13h+）后会话过期、
  重启时又被清掉（事故时 `user_sessions` 为空），页面里的请求全部 401；桌面端没有 401
  重进逻辑（只有手机壳有），所以只能吃到一句误导的 E4010 文案。截图里那句
  "这个请求不是从本机直接发起的"其实是 `source==='network'` 的**分支文案**，被用在了本机请求上。

## 修法

1. **`GET /shell/enter?secret=<local_secret>`**（`auth.SHELL_ENTER_PATH`，guard 内处理）：
   - 只认**本机直连**：`isDirectLocalRequest()` = peer 回环 + 无 `X-Forwarded-For`/`X-Real-IP`/`Forwarded`
     + Host 是本机名（含本机网卡地址 / hostname）。
   - 再比 `<数据目录>/local_secret`（0600，定长比较）；通过才 `store.createSession(userId, {kind:'shell'})`
     并发 `bandi_sid`，302 回 `/`。
   - 反代/局域网即使知道 secret 也不认（secret 本来就不出这台机器）。
   - 没有任何账号（零账号机器）时不做，继续走登录/建号页。
2. **shell 会话的寿命**（`store/users.mjs`）：`kind='shell'` → **空闲 7 天 / 绝对 180 天**。
   依据：这张会话的凭据是本机 0600 文件，和 `bandi_token`（Cookie 一年）同一档信任；
   而桌面壳里**没有输密码的地方**，沿用 30 分钟空闲闸必然掉线。
3. **桌面壳**（`apps/desktop/shell.mjs` 的 `windowUrl`）：探测到 `/api/state` 401 时，窗口开到
   `/shell/enter?secret=…`（不再用 `?token=`）；探测不到/回环免鉴权形态 → 直开原 URL；
   没有 `local_secret`（老数据目录/只读盘）→ 退回旧 `?token=` 路径。
4. **文案**：本机直连（loopback peer、无转发头）的 E4010 改成
   "需要登录（本机请求也要账号会话；桌面壳会自动重新进门）"，不再说"不是从本机直接发起的"。

## 边界 / 安全

- `/shell/enter` 不是"有秘密就放行"：**本机直连 + 文件秘密**两个都要；反代头、Host 伪造、
  trust-proxy 声明、错/空 secret、`BANDI_LOCAL_SECRET=off` 都进不来（`smoke-shell-enter` 钉住）。
- 不新增权限模型：进门后还是那张 `bandi_sid`，权限判定仍走 `decide()`；operator 令牌路径一个字没改。
- 秘密不落日志：shell.log 只写"用本机密钥自动进门"，不打印 secret；审计里不会出现 query。
- 老壳（已发布 1.5.x 没有新 `shell.mjs`）不受影响：仍走 `?token=` → 登录页，服务端兼容。

## 验收

- 新增 `apps/server/src/smoke-shell-enter.mjs`（临时数据目录 + 临时端口，默认对外监听）：
  本机直连+对 secret → 302+会话、能开面板；`kind=shell` 空闲闸按天；错 secret 不进且文案不撒谎；
  反代带 secret 不认；令牌路径不回归。
- `smoke-auth` / `smoke-shell` 全过；全量 `node tools/run-smokes.mjs` 60/60。

## 后续（未做）

- 面板在**运行中**会话失效（登出/超过 7 天空闲/秘密轮换）时，桌面端仍只有错误 toast，没有
  "重新进门一次"的页面级兜底；手机壳有 `BandiShell.sessionExpired` 可参照，桌面可加
  `location.reload()` 或 `/shell/enter` 重进（需要把 secret 临时放 sessionStorage，别进地址栏）。
