## 一、结论

**把「多机协同」从产品主线降为可选项。** 每台机器跑完整的单机版；远程访问用隧道解决；总机从「拥有状态的中心」退成「可选的转发层」。

代码不动主干——单机本来就是默认形态。要做的是**停止在节点上补齐总机功能**，把多机相关入口和文档降级为实验特性。

## 二、判据

规律：**状态在总机、文件在节点 → 总机每加一个功能，就多一个「节点上怎么用」的窟窿。**

已确认的例子：

| 功能 | 在节点上 |
| --- | --- |
| 项目工作区 | 建不了；只有 git clone 或手配路径映射两条路 |
| 工作区文件（路径 pill） | 按总机磁盘解析，节点上的产出看不到 |
| 连接器 / MCP | 不注入节点（`node.mjs`：不把总机那套地址和凭据带过去） |
| 项目仓库 | 仓库 clone 在总机，节点各有一份 |
| 瘦客户端 | 面板是总机的，本机库空着 |

这不是缺陷清单，是分层本身的税。

**反向判据**：只有当你确实要「跨机一个看板」或「云上常驻大脑 + 本地算力」时，这个税才值得交。

## 三、目标形态

```text
机器 A（台式机）          机器 B（笔记本）          机器 C（云/VPS，可选）
完整班底 :8787            完整班底 :8787            完整班底 :8787
   ↑ frpc                    ↑ frpc                    ↑ frpc
   └──────────── frps（只转发，不存状态、不派活）────────────┘
                          浏览器 / 手机
```

三条原则：

1. **一台机器 = 一个完整实例**：自己的库、项目、员工、会话、流程；
2. **一台机器 = 一份数据**：不跨机共享状态，也就不需要「哪台是权威」；
3. **中心只转发**：frps 不认识项目，也不派活；它挂了只影响远程访问，不影响本地使用。

- 保留：单机的全部功能；已有的隧道前提（`BANDI_HOST` / `BANDI_ORIGINS` / 访问令牌）。
- 放弃：跨机统一看板、跨机排队、跨机流程、瘦客户端「加入总机」。
- 替代：真要跨机协作 → 项目走 git 仓库 + PR（[git-repos](../../apps/server/src/git-repos.mjs) 已有）。

## 四、前提（先答这个，可能一票否决）

**常驻服务（飞书机器人 / 定时任务 / PR 巡检）和代码，是不是在同一台机器？**

- **是** → 降级成立，那台机器就是「带代码的常驻机」，隧道出去即可。
- **不是**（云上常驻、代码在本地）→ 降级会丢掉「云上收到飞书消息 → 派到本地机器跑」这条链。只能二选一：
  - 把常驻机搬成有代码的那台；或
  - 保留一个**最小总机**（只做派活，不做统一看板）。

## 五、隧道选型

| 方案 | 适合 | 代价 |
| --- | --- | --- |
| tailscale | 私有网络，只有自己的设备能进 | 每台装客户端；对外分享不方便 |
| cloudflared Tunnel | 走域名 + Cloudflare Access 身份 | 依赖 Cloudflare；配置稍多 |
| frp | 有自己的 VPS，想完全自控 | 自己维护 frps、TLS、认证 |

建议：自用优先 tailscale；要给手机/外部人看用 cloudflared + Access；已经有机房 VPS 就 frp。**三者都不改代码**，只是把 `127.0.0.1:8787` 接出去。

安全底线（写进 deploy 文档）：

- 服务只监听回环，隧道在机器上连回环；
- 监听非回环时令牌必开（已有规则）；
- 一律 HTTPS/TLS；
- 别把 `0.0.0.0:8787` 直接放公网。

## 七、实施顺序

1. **先答 §四 的前提**（一天内，不写代码）。
2. **文档先行**：deploy 加隧道一节；形态决策追加降级说明；README 里「想多台机器一起干活」改成「可选 / 实验」。（半天）
3. **入口降级**：设置 → 运行时页把「加入总机」收进实验区；客户端的引导文案改成「这是本机」。（一天）
4. **观察期（2–4 周）**：不删代码，看是否真的还有人用多机。
5. **再决定删不删**：顺序是 前端入口 → 路由 → `node.mjs` → 表与文档；每层都能停。

## 八、验收

- 三台机器各一个地址，各自能建项目、派活、看文件，互不影响；
- 外面通过隧道能打开任一台并正常操作；
- 不再出现「这个功能在节点上用不了」的提示；
- 关掉转发层，本地班底照常用。

## 九、风险与回退

- **固有代价**：那台机器关机 / 休眠，远程就打不开；没有跨机看板和跨机排队。要接受。
- **暴露面**：隧道后面是**能执行命令的完整应用**，必须带身份（Access / tailscale / 强令牌）。
- **回退**：代码不删，随时能开回多机；不做破坏性数据迁移。
