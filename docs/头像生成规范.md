# 头像生成规范

> 目的：让任何一次「给数字员工/专家生成头像」的产出风格统一、免调参数。
> 产物落位：`apps/web/avatars/<id>.png`（256×256，UI 显示 26~58px，256 足够）。

## 一、固定风格 Prompt

### 1. 新建头像（文生图）

```
Flat painterly soft-shaded cartoon avatar portrait of <角色描述：性别/职业/发型/眼镜/衣着/手持物>.
Medium shot showing head, shoulders and upper chest only; the head takes up roughly
half of the frame height. Character horizontally centered with comfortable empty
space above the hair. Solid muted <底色描述> background with subtle paper texture
and a soft vignette. Simple shapes, clean edges, warm friendly expression.
No text, no watermark, no border, no frame.
```

- 生成尺寸固定 **1024x1024 方图**（不要竖版——人物比例不可控）。
- 底色从下方色板选一个**未被占用**的颜色，或扩展色板（保持低饱和、偏灰调）。
- 每次生成消耗约 5-10 credits。

### 2. 修改已有头像（图生图，优先用这条）

需要「去瑕疵 / 换背景色 / 调构图」时，**必须用原版头像做 image-to-image**（input_fidelity=high），
不要从零生成——从零生成的风格（扁平矢量 vs 厚涂）和人物长相都不可控：

```
Keep this character and art style EXACTLY the same — same painterly soft-shaded
cartoon style, same face, hair, glasses, clothing, props, same muted textured
background. Fix ONLY: <要修的点，如 remove the black artifact above the head /
recompose so there is comfortable space above the hair>. No text, no watermark.
```

## 二、固定工序（免调参）

```bash
# 1. 裁剪缩放（自动：水平居中 + 底边避开水印带 → 256）
node tools/avatar-process.mjs <源1024.png> apps/web/avatars/<id>.png [水平偏移px]

# 2. 目测校验（居中度/头顶留白/水印/瑕疵），必要时：
node tools/avatar-nudge.mjs <输入> <输出> <下移px>   # 内容下移补头顶留白（顶部行延续填充）
node tools/avatar-debox.mjs <输入> <输出>            # 修补头顶杆状瑕疵（左侧背景条翻转贴入）
```

- **水印**固定叠印在整图右下角（实测 x≥907、y≥960 @1024），工序窗口底边距下沿 68px，自动排除，不要在提示词里做文章。
- 居中度数值检测在带纹理背景上不可靠（暗角/光斑被计入“人物”），**最终以目测为准**。
- 落盘后刷新页面即生效（静态文件），无需重启服务。
- 动过手之前先备份原图到 `tmp/avatar-backup/`。

## 四、反面清单（踩过的坑）

- ❌ 让模型画黑底/边框来「承载水印」——执行不可靠，构图会被挤压。
- ❌ 用品牌印盖水印——头像圆形裁切+小尺寸，盖印比水印更丑。
- ❌ 竖版 1024x1536 再裁——人物大小不可控，会出「大头照」。
- ❌ 从零生成已有角色——风格/长相漂移（扁平矢量 vs 厚涂一眼假）。
- ❌ 提示词里求「人物小一点」来救构图——不如图生图重排。
