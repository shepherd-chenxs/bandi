> **v2.1 去缝**：应用图标去掉两片之间的缝，两片沿竖直直径贴合为一条分割线，
> 右片下沉错位不变。切口改由**分色 + 错位**承担，小尺寸可读性更好。
> 辅助图形「合」（合拢交付态）保留原发丝缝，两态对比仍在。

## 一、品牌内核

**一句话**：班底 = 一支听你调遣的 AI 数字员工队伍——你点名谁，谁上场；你全程看得见，随时能接管。

**定位陈述**：对一个需要"把活交出去又不敢完全放手"的人来说，班底是**可接管的 AI 劳动力系统**：
不是工具箱，不是聊天框，而是一支看得见、管得住、停得下的队伍。算力在你自己机器上。

**人格坐标**：掌柜，不是极客。沉稳（8/10）、专业（8/10）、亲和（4/10）、装饰（2/10）。
**审美禁区**：网红流水线、赛博霓虹、AI 蓝紫渐变、拟物 3D 光泽。

## 二、标识释义「分玉」

《说文》：「**班，分瑞玉也。从珏从刀**。」——"班"的本义是用刀把一块玉分开，
两人各执其一。分而后成班。

这个动作就是产品的核心行为：**把一整块活切开、派下去、人手一件、再合成成品。**

| 形 | 义 |
| --- | --- |
| 圆 | 一件完整的活 / 一个完整的班底 |
| 竖直分割线 | 那道**随时可以插手的切口**——接管（两片贴合，靠分色显形） |
| 右片下沉的错位 | 成员不在同一进度上（并行、接力、有人已交付） |

三层语义都指向同一句话：**它是被分过的，所以你插得进去。**

## 三、标识家族

| 文件 | 用途 |
| --- | --- |
| `bandi-icon-dark.svg` | **应用图标主用**：墨底反白（任务栏、Dock、安装包、关于页） |
| `bandi-icon-light.svg` | 浅色系统环境 / 浅底物料 |
| `bandi-icon-mono.svg` | 单色场景（水印、打印、深浅不可控的底），`currentColor` |
| `bandi-icon-favicon.svg` | **≤48px 专用光学版**（错位加深、单色、无缝） |
| `bandi-lockup-dark/light.svg` | 横向组合（README、启动页、关于页） |
| `bandi-auxiliary-mark.svg` | 辅助图形「合」：交付态 / 空状态 / 加载完成 |
| `bandi-logo-sheet.html` | 一页总览预览 |

主用版是**墨底反白**，不是浅底全色：图标在深色任务栏、深色 Dock、深色启动器里出现概率最高，
一个墨方块在任何底上都立得住；浅底全色版给打印与浅色物料。

## 四、色板

| 名 | 值 | RGB | 印刷（四色） | 用途 |
| --- | --- | --- | --- | --- |
| 墨 | `#12161A` | 18,22,26 | 单黑 K90 / Pantone Black 6 C | 底、字、浅底上的主片 |
| 玉青 | `#2F7E74` | 47,126,116 | C64 M2 Y10 K51（近 5523 C） | 浅底上的次片、链接、主按钮 |
| 浅玉 | `#5FB3A3` | 95,179,163 | C45 M0 Y25 K5 | **仅限深底**（深底上玉青会闷） |
| 朱砂 | `#C8402F` | 200,64,47 | C0 M68 Y77 K22 | **只给"人"**：需人工下令/接管的节点 |
| 米白 | `#F2F1ED` | 242,241,237 | 纸白 | 深底上的主片、正文 |
| 浅底 | `#F7F7F4` | 247,247,244 | — | 浅色版底 |
| 暖灰 | `#888780` | 136,135,128 | K55 | 副行小字 |

**三条硬规则**：
1. **一幅画面只许一处朱砂。**朱砂是"轮到你了"的信号，不是装饰色。
2. 深底一律用浅玉 `#5FB3A3`，浅底一律用玉青 `#2F7E74`；不要跨底套用。
3. 不用 AI 蓝紫。玉青是这套标识的行业差异点，也是"玉"这个母题的唯一颜色落点。

## 五、构造与网格（100 单位坐标系，可直接转曲）

```
圆      r=40，圆心 (50,44)
切口    竖直直径 x = 50（v2.1 去缝：两片贴合为一条分割线）
两片    圆被直径切开的半圆（圆弧 + 直径闭合）
右片    沿 +y 偏移 off
```

| 档 | off | 适用 |
| --- | --- | --- |
| 全版 | 12 | ≥128px |
| 光学版 | 16 | 33~127px |
| 极小版 | 22 | ≤32px |

- 弓形路径（全版）：左片 `M50 4 A40 40 0 0 0 50 84 Z`；右片 `M50 4 A40 40 0 0 1 50 84 Z` + `translate(0 12)`。
  右片用 `sweep=1`（顺时针经右侧），左片 `sweep=0`（逆时针经左侧），方向反了会得到补集。
- 图标画布 512，mark 宽占 54.6%（约 280），整体居中；错位会把重心压低，`cy_mark = 44 + off/2 - 0.2` 做光学校正。
- 容器：圆角方块 `rx=110`（≈21.5%，跟 Windows 11 应用栅格）；iOS 用直角底交给系统裁。
- **安全空间**：标识四周留 mark 高度的 1/4，任何文字、边框不得进入。

## 六、小尺寸规则（必修课）

1. ≤48px 一律用 `bandi-icon-favicon.svg`，**不要拿主版缩放**——全版 6 单位缝在 16px 上只有 1.2px，抗锯齿一糊就成实心圆。
2. ≤32px 去第二色只留米白：1~2px 的色差读不出来，**形状比配色重要**。
3. 极小版整体放大 1.15（缝加宽后视觉会显瘦）。
4. 屏显最小 16px；印刷最小 8mm。小于此值改用墨色整圆版（自暴自弃式退化，仅限托盘/水印）。

## 七、产品内语法：让 VI 变成界面的语义

这是这套标识最值钱的地方——它不止是个图标，是一套**能读状态的颜色语法**：

| 场景 | 用色 | 含义 |
| --- | --- | --- |
| 事件流里 AI 的思考/工具/回复 | 玉青 | 机器在干 |
| 「等待你放行」「等待接管」的节点 | 朱砂 | 轮到你了 |
| 已交付 / 归档 | 墨（灰阶） | 收工 |
| 流程节点连线 | 暖灰 | 路径 |

- 卡片状态点、看板列头、按钮主色沿用同一套：**不要另起一套状态色**。
- 加载/启动动效：两片从"合"到"分"再回"合"（`auxiliary-mark` ↔ `icon`），只用 `transform` 位移，
  不做透明度闪烁；周期 1.2s，`ease-in-out`。
- 左栏 rail / 导航 logo：22px 用反白极小版（缝 18 单位），不带第二色。

## 八、禁用清单

1. 不旋转、不镜像（右片永远下沉；左片永远在上）。
2. 不加渐变、阴影、描边、发光、玻璃质感——高级感来自克制。
3. 不调换两片颜色、不改缝宽与错位量（那是三档光学参数，不是自由变量）。
4. 不把两片拆开单独使用（拆开就不是"班"了；要表达"分"请用辅助图形「合」的反向动效）。
5. 不拉伸、不压扁、不在圆外加框。
6. 不把朱砂用在标识本身——标识只有墨/玉青/米白三色。

## 九、权利与合规

- 几何全部为本方案原创构造（圆弧 + 弦的解析解），不来自任何字库或素材站，无字体/素材授权风险。
- **中文字标已提供转曲版（2026-11-10）**：`bandi-wordmark-zh.svg`（横排「班底」）与
  `bandi-wordmark-stacked.svg`（班底 + BANDI 竖排，与 rail 顶部字标同构），由
  `make-wordmark.py` 从 **Noto Sans SC（OFL，可商用）wght=700** 实例化后抽曲线生成，
  1em = 100 单位、中文字距 -1%、西文字距 0.16em，紧贴墨迹边界。**改字/改字重必须重跑脚本，
  不要手改路径**。正式印刷、对外物料、商标申请一律用转曲版，不得把字体文件作为 logo 资产分发。
- 商标建议：以**中文「班底」+ 分玉图形**组合申请第 9 类（软件）、第 42 类（SaaS/技术服务）；
  图形标单独申请可提高维权效率。申请前请做 CNIPA 近似检索。
- 本规范是设计侧建议，不构成法律意见。

## 十、生成与落地

- **唯一生成入口**：`python apps/desktop/make-icon.py [--preview|--only desktop|web|mobile|android]`。
  改几何/改色，只需要改这一个脚本 + 四个 SVG；脚本不解析 SVG，三处必须一起改。
- 输出：桌面（`icon.png` 512 / `icon.ico` 16…256）、Web（512/192/180/32/16）、
  移动壳（tauri 资源 + Windows Store 资产 + `icon.icns`）、安卓（五档 mipmap，含 `_round` 与自适应前景层）。
- ICO 是**手拼容器**（PNG-in-ICO，每档单独重绘）；icns 也是手拼（`icp4…ic09`）。
  交给 Pillow 从大图缩，16px 那张必然是糊的。
- 脚本写完会顶 `build.rs` 的 mtime——它的 `rerun-if-changed` 不盯 `icon.ico`，
  只换文件 cargo 不会重跑 build 脚本，exe 里还是旧图标（2026-10-15 实测）。
- 生效时机：Web 刷新两次内换新（SW 缓存）；桌面 exe 要重新 `cargo build`；安卓要重新 `assembleDebug`。

## 版本沿革

| 版本 | 日期 | 标识 | 退场原因 |
| --- | --- | --- | --- |
| v1.0 | 2026-11-10 | `b·i` 字标（铜金连接点） | 解释依赖英文语感（b and i），中文用户读不到 |
| v1.1 | 2026-11-10 | 牛头剪影（白底磁贴） | 用户改要全身、要简笔画 |
| v1.2 | 2026-11-10 | 全身牛 · 简笔画线描 | 与"多 agent 协作平台"的品类语义不直接相关；细线在 16px 依赖加粗补救 |
| **v2.0** | **2026-11-10** | **分玉（圆 + 切缝 + 错位）** | **现行** |

v2.0 的方法论差异：前三版都是"给产品找个吉祥物/字标"，这一版是**从品牌名的字源里长出来的**，
标识本身就是一句话（分玉成班），所以它能直接长成产品里的状态色与动效语法。
